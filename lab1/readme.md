First lab task Algorithm RSA: Develop a console or window application 
in an object-oriented programming language that implements encryption and
decryption of the contents of a text or executable file using the asymmetric 
RSA algorithm. The program should request the name of the input and output files, 
the type of cipher and the input parameters for performing cryptographic transformations. 
The input parameters are: e – public encryption key and n – the product of 
two coprime numbers p and q. Using the extended Euclid algorithm, calculate the value d – private decryption key.

In this file presented the working on program and block scheme of this program (on UKR).
