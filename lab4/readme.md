Develop a console or window application in an object-oriented programming language that implements 
encryption and decryption of the contents of a text or executable file using the elliptic curve apparatus. 
The program should request the name of the input and output files, the type of cipher, and input parameters for performing cryptographic transformations.
The input parameters are: elliptic curve: p=751; a= -1; b=1; E751(-1,1); y2 = x3-x+1(mod751); generating point: G = (0, 1).
