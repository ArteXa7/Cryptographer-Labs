Develop a console or window application in an object-oriented programming language that implements 
encryption and decryption of the contents of a text or executable file using the asymmetric El-Gamal algorithm.
The program should request the name of the input and output files, the type of cipher, and input parameters for 
performing cryptographic transformations. The input parameters are: p – a large prime number,
a – the root of a prime number p; x – the value of the private key.
